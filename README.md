## Selected Public Engineering Work

### [NestJS Chapa SDK](https://github.com/Sye-1321/nestjs-chapa)

Community maintained NestJS integration for Chapa payments, published on npm as [`@sye1321/nestjs-chapa`](https://www.npmjs.com/package/@sye1321/nestjs-chapa). It provides typed APIs, verified provider contracts, explicit retry boundaries, raw body webhook verification, ESM and CommonJS packaging, consumer compatibility testing, and a production focused release process.

Finance grade merchant payment platform simulation focused on idempotent financial commands, immutable double entry accounting, transactional outbox and inbox delivery, signed webhooks, settlements, deterministic reconciliation, and failure recovery.

Production oriented NestJS reference service focused on application startup, PostgreSQL readiness and recovery, bounded graceful shutdown, request context isolation, RFC 9457 error boundaries, observability, hardened containers, and failure focused process, integration, and container testing.
