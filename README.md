# Sye Balga

**Full-Stack Software Engineer | Distributed Systems · Financial Systems · Software Architecture**

I'm a full-stack software engineer based in Addis Ababa, Ethiopia, working across frontend and backend development. I build web applications using **React and Next.js**, alongside backend systems developed with **TypeScript/NestJS, Java/Spring Boot, and C#/ASP.NET Core**.

I have professional software development experience at **Vite Technologies PLC**, working with microservice-based systems and production-oriented application architecture. My engineering work emphasizes system reliability, concurrency, data integrity, failure handling, and predictable behavior under real-world conditions.

## Selected Public Engineering Work

### [SettleFlow](https://github.com/Sye-1321/SettleFlow)

**TypeScript · NestJS · PostgreSQL · RabbitMQ**

A financial platform simulation exploring correctness and reliability in transactional systems. Implements idempotent financial operations, immutable double-entry accounting, transactional outbox/inbox messaging, signed webhooks, settlements, deterministic reconciliation, and failure recovery.

### [Vite Ride Backend Architecture](https://github.com/Sye-1321/vite-ride-backend-architecture)

**TypeScript · NestJS · gRPC · MongoDB · Redis**

A sanitized engineering case study derived from professional backend development work at Vite Technologies. Demonstrates microservice architecture, multi-tenancy, authentication and authorization, transactional messaging, real-time infrastructure, observability, and automated verification.

### [PayLab](https://github.com/Sye-1321/PayLab)

**Java · Spring Boot · PostgreSQL · Testcontainers**

A provider-neutral payment resilience laboratory for evaluating payment integrations under ambiguous outcomes, concurrent requests, duplicate operations, unsafe retries, and webhook failures. Uses fault injection and observable evidence to produce reproducible conformance results.

### [NestJS Chapa SDK](https://github.com/Sye-1321/nestjs-chapa)

**TypeScript · NestJS · SDK Development · npm**

A community-maintained NestJS integration for Chapa payments, published on npm as [`@sye1321/nestjs-chapa`](https://www.npmjs.com/package/@sye1321/nestjs-chapa).

Provides typed payment APIs, explicit retry boundaries, raw-body webhook verification, normalized errors, ESM/CommonJS compatibility, consumer testing, and an automated release process.

### [Ride Dispatch](https://github.com/Sye-1321/ride-dispatch)

**C# · ASP.NET Core · Entity Framework Core · PostgreSQL/PostGIS**

A geospatial ride-dispatch service implementing driver eligibility evaluation, candidate ranking, explainable allocation decisions, time-limited offers, and concurrency-safe assignments. Emphasizes database-backed consistency, scheduling constraints, and automated verification.

### [NestJS Production Starter](https://github.com/Sye-1321/nestjs-production-starter)

**TypeScript · NestJS · PostgreSQL · Docker**

An executable reference for building reliable backend services. Covers application startup, database readiness and recovery, graceful shutdown, request-context isolation, structured error handling, observability, container hardening, and failure-focused automated testing.

### [Multi-Vendor Delivery Platform](https://github.com/Sye-1321/multi-vendor-delivery-platform)

**TypeScript · NestJS · MongoDB · Socket.IO**

A tenant-aware ordering and delivery backend implementing transactional checkout, concurrency-safe order fulfilment, courier assignment, resource-scoped authorization, authenticated real-time updates, and durable notification processing.
